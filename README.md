# Storyboard Técnico: "Hazte Industrial"

Ejemplo de storyboard técnico para la asignatura de Tecnología - 2º Bachillerato

## 📋 Descripción

Este proyecto contiene un storyboard técnico completo del vídeo "Hazte Industrial", creado como material didáctico para enseñar conceptos de lenguaje audiovisual a estudiantes de secundaria.

### Contenido:
- **4 planos** con dibujos ilustrativos
- Información técnica completa de cada plano (tipo de plano, ángulo, movimiento, duración, etc.)
- Notas de producción detalladas
- Análisis narrativo y técnico

## 🎓 Uso educativo

Este storyboard está diseñado como ejemplo para que los estudiantes:
- Comprendan la estructura de un storyboard técnico
- Aprendan vocabulario audiovisual
- Analicen secuencias narrativas
- Creen sus propios storyboards basándose en este modelo
